## Tool links in the post gate 2026-10-31 (lane `lane/t-20261031-landing-post-tool-links`, BM-366)
- `tests/blog-plan.test.mjs` now fails on a dead `/tools/` link in any post or open topic (site-relative or on buffermint.com): a tool not in `../buffermint-tools/src/<category>/_tools.json` (internal workflow steps excluded), a hidden tool, a category without listed tools, or a workflow not in `src/recipes-live.json`. This replaces the diagnostic-only check, so a tools change that hides a linked tool now fails landing lanes until the link is fixed. With no checkout the test skips and says why; a checkout that is there but corrupt, partial or reshaped fails it, so the gate can't switch itself off. Drafts (`published: false`), code samples and HTML comments are not checked; `/tools/embed/`, `assets/`, `data/` and the known top-level files (`llms.txt` and so on) are outside the catalogue and pass. First run: no dead links in the 23 posts or the open topics, so `BLOG-PLAN.md` needed no link fix.
